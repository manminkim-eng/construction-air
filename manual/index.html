00이 매뉴얼에 대하여

건축공사 공기산정 시스템은 준비기간·작업일수·비작업일수·정리기간을 더해 공공 건설공사의 공사기간을 산정하고, A4 공기산정 근거서로 출력하는 웹 계산도구입니다. 비작업일수는 가이드라인 부록의 96개 기상 관측 지점 통계와 법정공휴일로 월별 계산합니다. 발주청 담당자와 설계자가 화면 순서대로 따라 하며 공사기간 산정근거를 만들 수 있도록 작성했습니다.

예제 A로 6단계를 따라 하면 공사기간 450일이 나옵니다. 계산 버튼은 없습니다. 값을 바꾸는 즉시 결과가 바뀝니다.

  1. 공사 정보·관측 지점공사명, 착공 예정일(예제 2027. 3. 2.), 총 공사비(50억원)를 넣고 「기상 관측 지점」에서 공사구역에 가장 가까운 지점(전주(146))을 고릅니다(3-1·3-2).
  2. 공사 유형·건물 규모공사 유형(일반건물)을 고르고 지상 5층 · 지하 1층 · 연면적 4,000㎡ · 건축물 유형(기타 건축물)을 넣습니다(3-3·3-4).
  3. 준비기간·정리기간「다음」을 누르면 준비기간 20일(일반건물 참고값)과 정리기간 30일이 들어갑니다. 현장 조건에 맞게 조정합니다(3-5).
  4. 작업일수 → 비작업일수 → 공사기간공종별 작업일수(합계 235일)를 확인·수정하고, 비작업일수 단계에서 기상조건(철근콘크리트공사 예시)을 확인합니다. 월별로 계산한 비작업일수 165일이 더해져 공사기간 450일이 됩니다(3-6~3-9).
  5. 산정공식과 비교결과 화면에서 부록 5 산정공식(기타 건축물)으로 구한 696일과의 차이(-35.3%)를 봅니다. 차이가 크면 작업일수와 기상조건 설정을 다시 검토합니다(3-10).
  6. 근거서 인쇄·저장「📄 A4 미리보기」에서 「인쇄 / PDF 저장」 또는 「JPG 저장」으로 공기산정 근거서를 남깁니다(3-12).

03화면별 기능 상세

입력·산출 탭의 5단계 순서와 나머지 탭 순서로 설명합니다.

3-1. 공사 기본 정보 (1단계)

  • 총 공사비 100억원 이상(시·군·구 발주는 50억원 이상)이면 결과 화면에 공사기간 적정성 심의 대상이 표시됩니다(4-10).
  • 착공 예정일은 과거 날짜도 넣을 수 있습니다. 법정공휴일 자료가 없는 해(2026년 이전 · 2035년 이후)는 가장 가까운 해의 값을 씁니다.

3-2. 기상 관측 지점

공사구역에서 가장 인접한 행정지역의 지점을 고릅니다. 여러 행정지역에 걸치면 가장 많은 면적이 포함된 지역, 관측 위치와 차이가 현저하면 주변 유사 지점을 씁니다(가이드라인). 같은 목록이 4단계에도 있어 거기서 바꿔도 됩니다.

3-3. 공사 유형

카드 아래 작은 글씨가 준비기간입니다. 가이드라인 「건설공사 유형별 준비기간(예시)」 12종과 일반건물이 있습니다(4-3). 유형을 바꾸면 준비기간 조정값은 초기화됩니다.

3-4. 건물 규모

층수는 공종별 작업일수(참고값)와 산정공식에 씁니다. 공동주택은 건축물 유형 선택이 없고 공동주택 식을 씁니다.

3-5. 준비기간·정리기간 (2단계)

  • 조정한 값은 다른 입력을 바꿔도 유지되고 「조정됨」 표시가 붙습니다. 공사 유형이나 안전관리계획서 선택을 바꾸면 예시값으로 돌아갑니다.
  • 준비기간·정리기간에는 비작업일수를 계상하지 않습니다(가이드라인). 아래 노란 칸은 용지보상·지장물 이설·문화재 시굴 같은 시공조건의 소요기간 예시입니다.

4-4. 비작업일수

비작업일수 = A + B − C 월별 A = 해당 월에 기후여건으로 작업이 불가능한 일수 고시 제10조 · 부록 3 B = 해당 월의 법정공휴일수 고시 제9조 · 부록 1 C = A × B ÷ 달력일수 소수점 첫째자리에서 반올림(고시 제8조①) 월 비작업일수 < 8일 → 8일 적용 주 40시간 근무제(고시 제8조② · 가이드라인)
근거내용
고시 제8조①비작업일수는 법정공휴일수와 기상조건으로 인한 비작업일수의 합계에서 중복일수를 제외하여 산출한다. 이 경우 중복일수 산정은 소수점 첫째자리에서 반올림한다
고시 제8조②주공정 및 주공정에 영향을 미치는 공종에 대하여 검토하며, 월별 비작업일수가 주 40시간 근무제에 따른 비작업일수보다 작을 경우에는 주 40시간 근무제에 따른 비작업일수를 적용한다
가이드라인주 40시간 근무제에 따른 비작업일수는 월 8일로 계산
고시 제9조법정공휴일 수는 해당 공사의 착수 예정일 기준으로 산출하고 계약의 착수일 기준으로 재산출할 수 있다
고시 제10조주공정에 영향을 미치는 기상조건을 반영하여 산출한다. 기상정보는 최근 5년 또는 10년 동안의 통계를 활용할 수 있다(①). 관계법령과 기준에서 공종별로 작업을 제한하고 있는 기상조건을 반영한다(②)

가이드라인의 월별 예시 표는 중복일수를 소수 한 자리로 보여 주지만, 프로그램은 고시 제8조①대로 정수로 반올림합니다. 그래서 같은 달이라도 예시 표와 0.1~0.5일 다를 수 있습니다.

4-8. 정리기간

고시 제12조 — 정리기간은 공사 규모 및 시설물 특성 등을 고려하여 산출한다. 가이드라인 — 정리기간은 공정상 여유기간(buffer)과는 다르며, 일반적으로 주요공종이 마무리된 이후 준공 전 1개월의 범위에서 계상할 수 있다. 정리기간에는 비작업일수를 계상하지 않는다. 프로그램 기본값은 30일입니다.

4-11. 프로그램의 계산 순서

1. 준비기간 = 공사 유형 예시(일반건물은 참고값) 또는 조정값 2. 작업일수 = Σ 공종별 작업일수 (참고값 + 수정 + 추가 공종) 3. 작업 착수일 = 착공 예정일 + 준비기간 4. 월별: A = Σ 체크한 기상조건의 월평균, B = 부록 1, C = round(A × B ÷ 달력일수) 적용 = max(A + B − C, 8), 작업가능 = 달력일수 − 적용 첫 달은 착수일 이후 비율만 사용 = min(남은 작업일수, 작업가능), 계상 = 적용 × 사용 ÷ 작업가능 5. 비작업일수 = round(Σ 계상) 6. 정리기간 = 30일 또는 조정값 공사기간 = 1 + 2 + 5 + 6 · 준공 예정일 = 착공 예정일 + 공사기간
계산 정확도비작업일수 계산은 같은 식을 파이썬으로 따로 짠 독립 구현과 무작위 400건을 대조해 모두 일치함을 확인했습니다(v5.1.0). 부록 3 추출값은 지점별 소계와 대조했습니다.
